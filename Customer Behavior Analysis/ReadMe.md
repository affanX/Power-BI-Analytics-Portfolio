## Project Overview

This project focuses on analysing customer purchasing behaviour to uncover meaningful insights, identify purchasing patterns, and support data-driven business decisions.

The project follows an end-to-end data analytics workflow, starting with data cleaning and exploratory data analysis in Python, followed by advanced SQL analysis using Microsoft SQL Server, and concluding with an interactive Power BI dashboard to visualise key performance indicators (KPIs) and business insights.

The main objective is to transform raw customer data into meaningful insights that can help businesses better understand their customers, evaluate purchasing trends, and improve their marketing and sales strategies.

## Tools & Technologies

- **Python:** Data cleaning, data manipulation, and exploratory data analysis.
- **Pandas:** Data processing and analysis.
- **Jupyter Notebook:** Python development and analysis environment.
- **Microsoft SQL Server:** Data querying and advanced business analysis.
- **SQL:** Filtering, aggregation, grouping, sorting, and answering business questions.
- **Power BI:** Interactive dashboards, KPI reporting, and data visualisation.

## Project Workflow

### 1. Data Cleaning & Analysis – Python

Python was used to prepare the raw dataset and ensure it was suitable for further analysis.

Key activities included:

- Importing and exploring the dataset using Pandas.
- Understanding the dataset structure, columns, and data types.
- Identifying and handling missing values.
- Checking for duplicate records.
- Performing data cleaning and preprocessing.
- Conducting exploratory data analysis (EDA).
- Identifying initial customer purchasing patterns and trends.

### 2. Advanced Data Analysis – SQL Server

The cleaned dataset was imported into Microsoft SQL Server for further analysis.

SQL was used to answer business-related questions and extract meaningful insights from the data.

Key SQL concepts and techniques used:

- `SELECT` and `WHERE` for retrieving and filtering records.
- `GROUP BY` for aggregating customer and purchasing data.
- `ORDER BY` for sorting results and identifying trends.
- Aggregate functions such as `COUNT()`, `SUM()`, and `AVG()`.
- `CASE WHEN` statements for conditional logic and customer segmentation.
- `ROUND()` for formatting numerical calculations.
- Common Table Expressions (CTEs) for structuring complex queries.

The analysis focused on answering business questions related to customer purchasing behaviour, product preferences, discount usage, customer segmentation, and review ratings.

### 3. Dashboard Development – Power BI

Power BI was used to develop an interactive dashboard that presents the key findings in a clear and accessible format.

The dashboard includes:

- Key Performance Indicators (KPIs) to provide an overview of business performance.
- Visualisations showing customer purchasing behaviour.
- Graphs highlighting product preferences and purchasing trends.
- Analysis of customer reviews and ratings.
- Insights into discount usage and purchasing patterns.
- Interactive filters and slicers to explore different aspects of the dataset.

The dashboard allows users to explore the data interactively and identify important trends without having to analyse raw records manually.

## Key Business Objectives

The project aims to answer important business questions, including:

- What are the most frequently purchased products?
- Which products receive the highest average customer ratings?
- What percentage of purchases involve discounts?
- How can customers be segmented based on their previous purchases?
- What patterns can be identified in customer purchasing behaviour?
- What insights can businesses use to improve customer engagement and sales strategies?
